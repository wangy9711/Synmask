# Synmask Selection and Combination Pipeline

This repository contains 2 Jupyter notebooks that demonstrate the step-by-step selection pipeline for Syn-motifs and combination pipeline for Synmask, based on structural and immunological criteria.

---

## 📘 System Requirements

- **Operating system:** Linux (tested on Ubuntu 18.04 LTS, Python 3.10).
- **Software dependencies (recommended versions):**
  - Python ≥ 3.8 
  - PyTorch ≥ 1.10 
  - HuggingFace Transformers ≥ 4.20 
  - NumPy, Pandas, scikit-learn, tqdm
  - Jupyter (for running the notebooks)
- **Optional but recommended:** GPU (e.g. NVIDIA CUDA) for ProtBert and AlphaFold2; 10 GB+ GPU memory recommended for full pipeline.
- **External tools (see below):** DSSP, S4PRED, netMHCpan-4.1, netMHCIIpan-4.1; AlphaFold2 optional.

---

## 🛠 Installation Guide

1. **Clone the repository**
   ```bash
   git clone https://github.com/wangy9711/Synmask.git
   cd Synmask
   ```

2. **Create a conda environment and install Python dependencies**
   ```bash
   conda create -n synmask python=3.10 -y
   conda activate synmask
   conda install pytorch -c pytorch  # or pip install torch
   pip install transformers numpy pandas scikit-learn tqdm jupyter
   ```

3. **External tools:** DSSP, S4PRED, NetMHCpan/NetMHCIIpan must be installed separately and added to your `PATH`; see the "External Tools" section for links. **Other external software, especially AlphaFold2, requires additional environment setup—please configure according to the respective official documentation;** we do not duplicate those instructions here.

**Typical install time:** Depends on network speed (package download). Python environment setup on a server is typically on the order of several to tens of minutes; external tools and AlphaFold2 add time as per their documentation.

## 🧪 Demo (Run on Example Data)

A small example dataset is provided in `example_data/` (including PDB-derived inputs and intermediate CSVs from the selection pipeline) so that users can run the software without their own data.

- **motif_selection.ipynb (demo):**
  1. Open `motif_selection.ipynb` in Jupyter.
  2. Copy the contents of `example_data/` into your working directory, or set the notebook’s input/output paths to point to `example_data/` (e.g. use `./example_data/step1_disordered.csv` as input where the notebook expects `step1_disordered.csv`).
  3. Run **Step 2** (filter unreasonable motifs) and **Step 3** (filter amino acids) on the provided `step1_*` files; then run **Step 4** (secondary structure) if S4PRED (and optionally ProtBert) are installed.
  - **Expected output:** CSV files such as `step2_disordered.csv`, `step3_disordered.csv`, `step4_*` (and optionally ProtBert/AlphaFold2 outputs), plus filtered FASTA and summary tables.
  - **Expected run time:** Step 1 (DSSP over a full PDB database) takes **several hours** on a server, depending on disk I/O and server load. For the demo using precomputed `example_data`, Steps 2–3 only take ~1–3 minutes on a server; Steps 4–5 (S4PRED, ProtBert, AlphaFold2) add minutes to hours depending on hardware and dataset size.

- **motif_combination.ipynb (demo):** Requires a motif list (e.g. `peptide.csv` with columns `ID` and `Sequence`). For a minimal check, run the first cells that define `sample()` and load data; replace the path to `peptide.csv` with a small CSV of your choice. Full pipeline run depends on S4PRED/ProtBert/NetMHCpan and sample size.
  - **Expected output:** Assembled Synmask sequences, diversity-filtered CSVs, and (if external tools are used) S4PRED/ProtBert/NetMHC result files.
  - **Expected run time for demo (sampling + diversity filter only):** ~1–5 minutes on a server; with external tools, scale with sequence count and hardware.

## 📖 Instructions for Use (Your Own Data)

- **motif_selection.ipynb:**  
  - **Input:** A directory of PDB (or mmCIF) files; optionally precomputed DSSP output.  
  - **How to run:** Execute the notebook cells in order. In Step 1, set `pdb_dir` (and `dssp_out_dir`) to your PDB directory and run DSSP as generated by the notebook. Use the produced `step1_disordered.csv` / `step1_missing.csv` as input to Step 2, then follow the pipeline through Step 3-5.  
  - **Output:** Filtered Syn-motif candidates and intermediate CSVs at each step.

- **motif_combination.ipynb:**  
  - **Input:** A motif list (e.g. `peptide.csv` with `ID` and `Sequence`) and, for full pipeline, the same external tools as in the notebook (S4PRED, ProtBert, NetMHCpan/NetMHCIIpan, optionally AlphaFold2).  
  - **How to run:** Set the path to your `peptide.csv` (and any output directories) in the first data-loading cells, then run the notebook in order.  
  - **Output:** Concatenated Synmask sequences, diversity and immunogenicity screening results, and merged tables.

- **Reproduction of manuscript results:** Follow the Methods section of the manuscript; run `motif_selection.ipynb` on the same PDB set and parameters as described, then run `motif_combination.ipynb` on the resulting motif set and the same allele list and thresholds. Exact reproduction may require the same versions of external tools and random seeds where applicable.

## 📘 Contents

- **`example_data/`**  
  Small demo dataset for testing the pipeline without a full PDB run: includes example PDB files (`PDB_split/`), and intermediate CSV outputs from the selection pipeline (`step1_disordered.csv`, `step1_missing.csv`, through `step4_*`). Use these as inputs when running the notebooks for a quick demo (e.g. from Step 2 onward in `motif_selection.ipynb`).

- **`motif_selection.ipynb`**  
  A complete workflow including:
	-	Extraction of disordered fragments from PDB structures
	-	Identification of unresolved (missing-density) regions from SEQRES/ATOM mismatch
	-	Multi-stage filtering to remove low-complexity motifs, linker-like patterns, and undesired residue compositions
	-	Secondary structure screening using S4PRED, ProtBert, and AlphaFold2+DSSP
	-	Final refinement via amino-acid substitution/removal and re-prediction
	-	Selection of intrinsically disordered Syn-motif candidates for synthesis

- **`motif_combination.ipynb`**  
  A complete workflow including:
  - Random generation and motif-based assembly of Synmask sequences
  - Diversity filtering based on motif usage
  - Secondary structure prediction using S4PRED, ProtBert, and AlphaFold2
  - Immunogenicity screening via NetMHCpan (MHC-I and MHC-II)
  - Motif repetition control to improve expressibility

- **`netMHCpan-4.1`**  
  Command-line tool for MHC class I binding prediction.  

- **`netMHCIIpan-4.1`**  
  Command-line tool for MHC class II binding prediction.  

## 🛠 External Tools

- [**S4PRED**](https://github.com/psipred/s4pred)  
  Used for fast secondary structure prediction of full-length Synmask sequences.  
  Model weights are available via the repository.

- [**ProtBert-BFD-SS3**](https://huggingface.co/Rostlab/prot_bert_bfd_ss3)  
  A transformer-based model for secondary structure prediction.  
  Integrated via HuggingFace Transformers and used for robust disorder region identification.

- **netMHCpan-4.1**  
  Command-line tool for MHC class I binding prediction.  
  Download the binary from the [official website](https://services.healthtech.dtu.dk/service.php?NetMHCpan-4.1).  
  Requires registration and academic license.

- **netMHCIIpan-4.1**  
  Command-line tool for MHC class II binding prediction.  
  Download available via the [official website](https://services.healthtech.dtu.dk/service.php?NetMHCIIpan-4.1).  
  Used for scanning potential CD4⁺ T-cell epitopes across multiple HLA class II alleles.

- **AlphaFold2**  
  Used for high-accuracy secondary structure filtering in the final stage.   
  [AlphaFold GitHub Repository](https://github.com/deepmind/alphafold)
